# ADR-0002：仓库形态与用例资产归属

| 字段   | 值                       |
| :----- | :----------------------- |
| 状态   | **已采纳**               |
| 日期   | 2026-07-25               |
| 决策人 | 项目初始化（按推荐默认） |

## 背景

PRD 要求「Runner 独立仓库；用例/夹具资产留在被测仓库」。引擎需要自测样例，又不能把正式题库绑死在引擎仓库。

## 决策

1. **仓库形态：单包**（非 monorepo）。模块用目录分隔：`case-engine` / `drivers` / `oracles` / `attribution` / `metrics` / `report` / `contract` / `cli`。
2. **正式资产 = 题库/考卷**：由被测项目持有；目录隐喻与根路径见 **ADR-0005**（`papers/` + `exam.json` + `items/` `papersets/` `rooms/` `materials/`）。引擎通过 `--project <path>` 指向该资产根。
3. **本仓库样例**：`examples/` / `templates/` 仅作自测与格式样板（解冻时迁到考卷目录名）。
4. **`40-评测工具/`**：保留为需求与 Phase 0 历史资产；不作为运行时默认资产根。兼容校验可对其中样例做回归对照。
5. **多被测**：`wanxiangshu` 只是首个适配样例；Fold/宿主入口均由 room（profile）配置，引擎不绑死单一产品路径。

## 后果

- 正面：符合 PRD；引擎可独立版本演进；被测侧资产与产品同仓；目录对业务方可读。
- 负面：跨仓库路径与 CI 编排需约定；本仓库不能单独声称「正式题库完备」；与 Phase 0 `cases/` 命名需迁移映射。
