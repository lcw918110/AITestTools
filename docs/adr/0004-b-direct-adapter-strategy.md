# ADR-0004：B-direct 评测框架适配策略

| 字段   | 值                                       |
| :----- | :--------------------------------------- |
| 状态   | **已采纳**（框架具体选型：待评审后锁定） |
| 日期   | 2026-07-25                               |
| 决策人 | 按推荐默认                               |

## 背景

PRD D3：B 轴 direct 通道「适配成熟框架，不自研矩阵引擎」。候选含 promptfoo、Inspect-AI。过早绑死某一框架有许可证/导出格式风险。

## 决策

1. **架构先定适配面，框架后锁**：`drivers/model-adapter` 只依赖两个稳定面：
   - **输入**：harness 统一的「评测作业」描述（题库、工具假应答、断言、repeats、模型列表）
   - **输出**：框架侧可解析的 JSON/结构化结果 → 收编为 `results.ndjson` + 归因标签
2. Phase 1 设计阶段产出 **选型评审表**（本地可跑、工具调用断言、JSON 导出、许可证、Node/TS 集成成本）；评审通过后再钉默认 adapter。
3. 门禁与主指标只挂 **收编后的 harness 指标**；不把框架专有指标直接进 gate。

## 后果

- 正面：换框架只改 adapter；符合 PRD 风险对策。
- 负面：首版要多写一层转换；选型评审前不能宣称「已集成某框架」。
