## 0. 一句话

**题库只干一件事：把「问什么」和「怎样算对」写清楚，并保证三种实验都能抽到同一套题。**  
录入与编辑必须让非引擎同学也能做完；规则宁可严，不可含糊。

---

## 1. 为什么重做

现行控制台题库区的问题（须消灭）：

| 问题                                                           | 为何不能忍                     |
| :------------------------------------------------------------- | :----------------------------- |
| 字段名是工程师黑话（`hosted_pass_token`、`bump-rev`、`notes`） | 维护者不知道自己在改什么       |
| 「新建」与「编辑」挤在同一屏                                   | 心智分裂，易误点               |
| 升 rev 可勾可不勾                                              | 语义变更可静默落盘，基线不可比 |
| 终态词与题干可互相矛盾                                         | 直播必挂，且难排查             |
| 删除无强确认                                                   | 一键毁掉配对题与测试集引用     |
| 创建成功 ≠ 校验绿                                              | 半残题可进库                   |

---

## 2. 用户只认三个动词

| 动词         | 人话                          | 系统必须保证                                           |
| :----------- | :---------------------------- | :----------------------------------------------------- |
| **录一道题** | 新加一道「问什么 + 怎样算对」 | 成对 OFF/ON、挂进所选测试集、校验绿，否则整笔失败      |
| **改一道题** | 改题干或改「怎样算对」        | **强制**升版本 + 必填原因；OFF/ON 同步；改完可一键校验 |
| **删一道题** | 这道不要了                    | 输入题号确认后，材料 / 成对条目 / 各测试集引用一并清掉 |

浏览、校验是辅助，不是第四个主流程。

---

## 3. 界面必须展示的结构

概念定义见 [00-glossary.md](00-glossary.md)（人题、引擎条目、测试集、三种实验）。页顶三行必须与术语篇一致，不可关。

```text
一道题（人看见的）
├── 题号          如 PAIRED-TASK-06
├── 题干
├── 怎样算对
├── 任务类型      item.tags（coding / workspace …）；不含 paired / plugin-* / effect
└── 引擎条目      系统自动写 OFF + ON 两份 JSON（无插件 / 有插件两侧）
```

界面禁止出现未解释的：`item`、`stimulus`、`oracle`、`papersets`、`rev`（可用「版本」代替）、`effect_pair`。

## 4. 范围

### 4.1 做（题库工作台 · 本 PRD）

| 能力     | 严格要求                                                                  |
| :------- | :------------------------------------------------------------------------ |
| 题列表   | 每行：题号、终态词、版本、完整度、任务类型；可按测试集筛（含「全部」）    |
| 录题向导 | 固定 4 步；第 1 步选题号与测试集（可新建）；第 3 步可选任务类型           |
| 改题页   | 主字段：题干、怎样算对、任务类型；高级区默认折叠；难度本刀不录入          |
| 删题     | 二次确认：手打题号                                                        |
| 校验     | 「检查题库」独立按钮；录题结束自动跑一次                                  |
| 只读说明 | 页顶三行用语取自 [术语篇](00-glossary.md)（题库、人题、三种实验），不可关 |

### 4.2 明确不做

- 在题库页配置模型 / Agent（那是运行环境页）
- 裸编辑整份 item JSON / expect oracle 图
- 多考卷库切换、远程题库、协作锁
- 把 OFF/ON 合并成「单题」协议（资产层仍成对；UI 只暴露「一道题」）
- 难度字段（T5 后半）；用途字段；完整测试集编辑器；改题页再挂另一套测试集

录题可选或新建测试集并写入该集正式名单；不在测试集上绑运行环境。

## 5. 严格规则（不可配置放宽）

### 5.1 题号

| 规则 | 说明                                                      |
| :--- | :-------------------------------------------------------- |
| 格式 | 必须匹配 `^PAIRED-TASK-[0-9]{2,}$`（如 `PAIRED-TASK-06`） |
| 唯一 | materials 目录名、`effect_pair`、列表主键三者同一字符串   |
| 禁止 | 小写、空格、路径符、自造前缀（录题入口不接受历史特例 id） |

> 历史题 `EVAL-B-PAIRED-TASK-OFF`（无 01）只读可编辑内容，**不允许**在 UI 里改题号。

### 5.2 题干（输入）

| 规则       | 说明                                                            |
| :--------- | :-------------------------------------------------------------- |
| 必填       | 去首尾空白后长度 ≥ 1                                            |
| 建议       | 明确写出要求模型输出的终态词                                    |
| **硬门禁** | 终态词（整词）必须作为子串出现在题干中，否则禁止保存 / 禁止创建 |
| 落盘       | 仅 `bank/materials/<题号>/prompt.txt`；UTF-8；末尾保证一个换行  |

### 5.3 怎样算对（判定）

| 规则     | 说明                                                                                                          |
| :------- | :------------------------------------------------------------------------------------------------------------ |
| 字段人话 | 界面写「怎样算对（终态词）」                                                                                  |
| 必填     | 非空；禁止空白、禁止含空格与换行                                                                              |
| 格式     | `^[A-Za-z0-9_-]+$`（与 hosted 词边界判定一致）                                                                |
| 同步     | 写入 OFF **与** ON 两侧的 `stimulus.hosted_pass_token`                                                        |
| notes    | 新题默认：`Seal with <终态词>. Use the repo and tools when the task requires it.`（不再写禁工具）；高级区可改 |

### 5.4 版本（原 bump-rev）

| 规则                   | 说明                                    |
| :--------------------- | :-------------------------------------- |
| 改题干或终态词或 notes | **必须**升版本，无勾选项                |
| 变更说明               | **必填**，长度 ≥ 4；写入 change_log     |
| 升哪些                 | OFF 与 ON 各升一版（只要该侧存在）      |
| 创建                   | 从版本 1 开始，说明固定为「控制台录题」 |

### 5.5 成对与挂入测试集（系统自动成对，用户只选一套）

录题成功时系统必须：

1. 写 materials
2. 写 `EVAL-B-<题号>-OFF` 与 `EVAL-B-<题号>-ON`
3. 挂入**所选测试集**的无插件 / 有插件两侧名单。可当场新建一套空测试集。不自动进 156 全量，除非用户选的就是全量。

缺任一步 → **整笔失败**，不得留下半套文件（见设计「事务」）。所选测试集文件不存在则失败。

### 5.6 删除

| 规则 | 说明                                         |
| :--- | :------------------------------------------- |
| 确认 | 对话框要求原样输入题号                       |
| 范围 | materials + OFF/ON 文件 + 所有测试集中的引用 |
| 之后 | 自动跑一次校验；失败则界面大红字（人工介入） |

### 5.7 校验

| 时机               | 行为                                                            |
| :----------------- | :-------------------------------------------------------------- |
| 用户点「检查题库」 | `item validate --check-fixtures`，展示人话结果：通过 / 失败条数 |
| 录题提交成功后     | 自动校验；失败则回滚本笔录题                                    |
| 改题保存后         | 不强制自动校验，但按钮旁提示「建议检查题库」                    |

## 6. 界面信息架构（易懂优先）

```text
题库工作台
├── 页顶说明（固定 3 行，不可关）
├── 主操作：[录一道题]  [检查题库]
├── 测试集筛选（含「全部」）
├── 题列表（点选进入「改题」）
└── 改题页 / 录题向导（互斥全屏或抽屉，勿同屏堆叠）
```

### 6.1 录题向导（4 步）

| 步  | 标题     | 用户填写                                                         | 下一步门禁                                                 |
| :-- | :------- | :--------------------------------------------------------------- | :--------------------------------------------------------- |
| 1   | 题号     | `PAIRED-TASK-NN`；必选测试集（可新建）                           | 格式合法且不存在；已选测试集                               |
| 2   | 题干     | 多行文本                                                         | 非空；禁止 Text-only / 禁工具 / 禁探索仓库                 |
| 3   | 怎样算对 | 终态词；「回复必须出现」「禁止出现」各一行（可空）；可选任务类型 | 终态词格式合法且出现在题干中；不与已有题撞名；任务类型可空 |
| 4   | 确认     | 只读预览：将创建的文件与所挂测试集                               | 用户点「确认录入」→ 落盘+校验                              |

### 6.2 改题页

| 区块         | 内容                               |
| :----------- | :--------------------------------- |
| 标题         | 题号 + 「无插件版本 / 有插件版本」 |
| 主区         | 题干、怎样算对、任务类型           |
| 必填         | 变更说明（为何改）                 |
| 主按钮       | 保存（隐含升版本）                 |
| 危险         | 删除（需再输入题号）               |
| 折叠「高级」 | notes 文本；只读展示 item id       |

禁止在改题页再放「新建」表单。

## 7. 成功标准（可测）

| ID  | 标准                                                                 |
| :-- | :------------------------------------------------------------------- |
| B1  | 新人只看页顶说明 + 向导，能在无文档情况下录成一道题并挂进所选测试集  |
| B2  | 任意保存路径都无法在「不写变更说明 / 不升版本」下改题干或终态词      |
| B3  | 终态词不在题干中时，创建与保存均被拒绝，并提示「请把终态词写进题干」 |
| B4  | 录题中途失败（磁盘或校验）后，磁盘无半套 materials/item/测试集脏数据 |
| B5  | 删除须手打题号；删后列表消失且校验绿                                 |
| B6  | 界面主路径无未解释英文协议名                                         |

## 10. 新题默认与试题标签

既有「录 / 改 / 删 / 检查」动词不变。新题默认改为：

1. **不要**再生成禁工具 notes，也 **不要** 再写 ON 探针 `assistant_completed`。
2. 判定至少「退出码 0 + 一条回复断言」；界面用「必须出现 / 禁止出现」，不开放通用正则编辑器。
3. 录题必选测试集（可新建）；不自动进 156 全量，除非选的就是全量。
4. 题干禁止 Text-only / 禁工具 / 禁探索仓库；终态词全库不撞名。
5. 冒烟例外仅 API `allowSmokeTextOnly`（默认关）；向导不暴露。

6. 试题 `tags` 只表示 [任务类型](00-glossary.md#任务类型)。禁止再写 `paired`、`plugin-off`、`plugin-on`、`effect`。录题向导第 3 步可选填写；列表与改题页展示并可改（改则升版本）。
7. [难度](00-glossary.md#难度)尚未录入（T5 后半）。[用途](00-glossary.md#用途)不属于题库。

材料播种（必须用仓库/工具才能过）已在 157–159 使用；新题材料仍由维护者准备，向导本篇不自动生成仓库补丁。
