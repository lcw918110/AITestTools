## 1. 操作台三页

顶栏三个入口：**测试** | **题库** | **运行环境**。测试页含测试任务 + 测试结果。一次开跑 = **测试集 × 运行环境**。

### 测试任务

- **是什么：** 操作台的组织单位。每一条绑定：测哪一类、哪套测试集、本题要跑的题目、运行环境快照、以及历次测试结果。可保存多条，JSON 落在评测项目 `eval-tasks/`。勾选不写回测试集文件。测模型 / 测万象术 / 测 Agent **只在新建时三选一**；打开已有任务只显示只读类型，换类型须另建一条。
- **不是什么：** 不是题库里的一道题（题号仍是 `PAIRED-TASK-*`）；不是「看板」；不含「用途」字段（本刀不做）。详情页不再出现类型三选一。
- **哪儿用过：** [需求 02](02-console-prd.md) · [设计 08](../v1-design/08-console-outline.md)

### 测试结果

- **是什么：** 某条测试任务下**某一次跑次**的呈现：逐条明细 + 针对这次明细的分析（Δ、CONTEXT 剔除、归因等）。打开任务默认看最近一次；任务下挂全部跑次，需要时再点更早一次。
- **不是什么：** 不是选题界面；不是「测试看板」（「看板」留给以后观察多次测试，本刀不用这个名字）；不在效果差出来之前画空的经济图。
- **哪儿用过：** [需求 02](02-console-prd.md) · [测试 03](../test/03-console-ops.md)

### 题库

- **是什么：** 维护「问什么」和「怎样算对」的工作台与资产。三种实验共用同一套人题。操作台上单独成页；列表按测试集筛；录题必选或新建测试集。
- **不是什么：** 不分「有插件题 / 无插件题」；不写对照成绩；不在这里配置模型 / Agent（那是运行环境页）。改题页本刀不提供「再挂进另一套测试集」。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [设计 09](../v1-design/09-bank-editor.md)

### 运行环境（操作台页）

- **是什么：** 顶栏第三页。在这里增改**模型**和 **Agent**，写入 `rooms/` 下的运行环境配置，并用 Hello World 级操作验证。通过后才出现在测试任务下拉。界面不说「考场」「共享目录」。
- **不是什么：** 不是测试集；不是测试任务里勾选的题目。`paired-off` / `paired-on` / `eval-model` / `eval-agent` 属于运行环境这一侧（磁盘实现），不进测试集下拉。
- **哪儿用过：** [需求 02](02-console-prd.md) · [设计 08](../v1-design/08-console-outline.md)

### 三种实验

- **是什么：** 测模型、测万象术、测 Agent。三类互斥，一条测试任务只选一种；一次只变一个主因子；共用同一套人题，只换选题（测万象术还换有无插件）。
- **不是什么：** 不是三套题库；不是操作台上多出来的第四块。引擎 A/B/C 是实现手段，不是这三种实验。无插件 / 有插件 / 同时跑**只属于测万象术**，不叠到测模型或测 Agent 上。
- **哪儿用过：** [测试 01](../test/01-wanxiangshu-ops.md) · [需求 02](02-console-prd.md)

## 2. 题与落盘

### 人题

- **是什么：** 人看见的一道题：题号、题干、怎样算对、任务类型（`tags`）、可选难度（尚未录入）。界面上称「题目」；题号如 `PAIRED-TASK-157`。
- **不是什么：** 不是磁盘上的一份 `*.item.json`；不是「测试任务」（那个词只指操作台上可保存的一条评测安排）。筛选和列表认题号。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [测试 01](../test/01-wanxiangshu-ops.md)

### 引擎条目

- **是什么：** 同一人题落成的 OFF / ON 两份 `*.item.json`，分别对应无插件 / 有插件跑法。题干与怎样算对相同。界面仍只暴露一道人题。
- **不是什么：** 不是两种题。UI 与选题只暴露人题（题目），不勾 OFF/ON 两行。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [设计 08](../v1-design/08-console-outline.md)

### 题干

- **是什么：** 给学生 / 模型的输入全文，落在 `bank/materials/<题号>/prompt.txt`。
- **不是什么：** 不是判定规则；OFF/ON 两侧共用同一份。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [product-eval README](../../examples/product-eval/README.md)

### 怎样算对

- **是什么：** 这道题怎样算过。人话在题库界面；协议里对应 `expect.oracles`（主判定）与暗号（辅助）。
- **不是什么：** 不是跑次里的过挂记录；改怎样算对必须升版本。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [测试 01](../test/01-wanxiangshu-ops.md)

### 任务类型

- **是什么：** 试题 `tags` 所表示的任务种类（如 coding、workspace）。录题向导可选；列表与改题页展示。空则不加标签。
- **不是什么：** 不是 `paired` / `plugin-off` / `plugin-on` / `effect`（已废弃，禁止再写）。不是过挂。不是测试任务上的「测模型 / 测万象术 / 测 Agent」。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [过程日志](../process/01-changelog.md)

### 难度

- **是什么：** 预给人看的题目难度字段。
- **不是什么：** 尚未录入；不在本篇写成已上线能力。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [过程日志](../process/01-changelog.md)（T5）

### 运行环境（任务快照）

- **是什么：** 这条测试任务怎么跑：类型（只读）+ 测万象术才有的有无插件 + 已验证的模型与 Agent。选一次记在任务 JSON 上，不随配置页改动自动变，要变就在任务上重选。测万象术「同时跑」= **同一套 Agent、同一套模型**，先无插件再有插件。测模型 / 测 Agent 固定无插件侧。
- **不是什么：** 不是测试集；不是「大家共用一间房间、任务去改它」。开跑时与测试集组合；引擎仍可能拼 `rooms/*.json`，界面不出现该目录名。
- **哪儿用过：** [需求 02](02-console-prd.md) · [设计 08](../v1-design/08-console-outline.md)

### 考场

- **是什么：** 引擎 / 磁盘用语：`rooms/*.json` 里的宿主冻结（有无插件、默认模型 / Agent）。CLI 与协议仍用此词。
- **不是什么：** 不是操作台给人看的概念。操作台只说「运行环境」。
- **哪儿用过：** [测试 01](../test/01-wanxiangshu-ops.md) · [ADR-0005](../architecture/adr/0005-naming-host-fold.md)

### 测试集

- **是什么：** 考哪些题：一份人题名单。界面下拉只按题目名单合并（效果小样本 / 校准 / 全量 / 冒烟 / 自建等）。磁盘仍是成对 `papersets/*.json`（无插件 / 有插件两侧），界面不出现 `paired-off`、`paired-on`、`eval-model`、`eval-agent` 等文件名。可新建一套空测试集。
- **不是什么：** 不是运行环境；不是这条任务勾出来的子集。不做完整测试集编辑器（不拆 OFF/ON 给人勾、不在测试集上绑运行环境）。原「组卷」对人即本词。
- **哪儿用过：** [需求 02](02-console-prd.md) · [需求 03](03-bank-editor-prd.md)

### 组卷

- **是什么：** 引擎 / 磁盘用语：一份 `papersets/*.json`，列出引擎条目并声明所绑房间。成对文件支撑同一测试集的无插件 / 有插件跑法。
- **不是什么：** 不是操作台下拉里的选项名。勾选「本题要跑的题目」不写回这些文件；录题挂入所选测试集时除外。
- **哪儿用过：** [需求 01](01-prd.md) · [测试 01](../test/01-wanxiangshu-ops.md)

### 材料

- **是什么：** 题干之外、工作区需要的文件（`bank/materials/` 下除 `prompt.txt` 外的播种）。效果题应让人必须用仓库 / 工具才能过。
- **不是什么：** 不是运行环境；不是测试集。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [测试 01](../test/01-wanxiangshu-ops.md)

### 暗号

- **是什么：** `hosted_pass_token`（终态词）。报告写「暗号：有 / 无」，作辅助对照。
- **不是什么：** 缺词或空输出不得一票否决整题；主判定是工作区等 oracle。
- **哪儿用过：** [测试 01](../test/01-wanxiangshu-ops.md) · [需求 03](03-bank-editor-prd.md)

## 3. 一次测试

### 测试集题目列表

- **是什么：** 某套测试集的正式人题名单。题库与选题下拉都展示这份名单（题号 / 任务类型 / 简介 / 题干）。
- **不是什么：** 不是运行环境文件名；不是「本题要跑的题目」。
- **哪儿用过：** [需求 02](02-console-prd.md) · [需求 03](03-bank-editor-prd.md)

### 本题要跑的题目

- **是什么：** 一条测试任务从当前测试集题目列表里勾出来的子集。只记在该任务上，不写回测试集文件。
- **不是什么：** 不是测试集本身；不是正式名单的编辑器。
- **哪儿用过：** [需求 02](02-console-prd.md) · [设计 08](../v1-design/08-console-outline.md)

### 模板

- **是什么：** 已并进「测试任务」：保存选题 + 配置（测万象术含有无插件）即一条可再开的任务。不再单做「套用模板」按钮。
- **不是什么：** 不改 `eval:paired` 默认绑 156 全量。
- **哪儿用过：** [需求 02](02-console-prd.md) · [过程日志](../process/01-changelog.md)（T3 已落地）

### 用途

- **是什么：** 计划中的测试用途字段：效果对照 / 校准 / 回归。
- **不是什么：** 本刀不做；不属于题库字段，也不写进试题 `tags`。
- **哪儿用过：** [需求 02](02-console-prd.md) · [需求 03](03-bank-editor-prd.md)

### 跑次

- **是什么：** 一次 `proctor run`（或操作台开跑）写下的结果目录：过挂、归因、Δ、暗号有无、配置回放。
- **不是什么：** 不写回试题 `tags`；不是测试集。
- **哪儿用过：** [需求 02](02-console-prd.md) · [测试 03](../test/03-console-ops.md)

## 4. 成绩与归因

### 过挂

- **是什么：** 某道引擎条目在某次跑次里的通过 / 失败。hosted 效果题主判定是 `workspace_assert`（超时仍跑工作区）；仓库全过则整题过。
- **不是什么：** 不是试题标签；不写回 `tags`。超时或非 0 退出本身不单独否决（见测试 01）。
- **哪儿用过：** [测试 01](../test/01-wanxiangshu-ops.md) · [需求 02](02-console-prd.md)

### Δ

- **是什么：** 同一批人题两侧（通常 OFF vs ON）通过率之差。效果结论用**剔除 CONTEXT 之后**的 Δ。
- **不是什么：** 不是已废弃的 `effect` 标签；156 全量跑次的数字不能直接当效果结论。
- **哪儿用过：** [需求 02](02-console-prd.md) · [测试 03](../test/03-console-ops.md)

### CONTEXT

- **是什么：** 失败归因六选一之一，表示上下文 / 会话 / 鉴权 / 额度 / 超时且材料未改等「任务环境没真正跑完」。效果对照里：超时且材料未改 → 记 CONTEXT，**该题不进 Δ**。
- **不是什么：** 不是「模型把题答错」（那是 `MODEL_TASK`）。额度失败必须记 CONTEXT，不得装成任务失败。
- **哪儿用过：** [测试 01](../test/01-wanxiangshu-ops.md) · [设计 07](../v1-design/07-hosted-attribution-tree.md)

### effect

- **是什么：** 已废弃的试题标签，曾被误用来筛「效果题」。
- **不是什么：** 不是过挂、不是 Δ。给人筛卷用测试集（效果小样本 / 校准 / 全量等）。
- **哪儿用过：** [过程日志](../process/01-changelog.md) · [设计 08](../v1-design/08-console-outline.md)

### 经济四格

- **是什么：** 弱模型开插件 vs 强模型关插件的对照读法（经济实验）。
- **不是什么：** 效果差出来之前不画空图。
- **哪儿用过：** [过程日志](../process/01-changelog.md)（T7） · [需求 02](02-console-prd.md)

### 归因

- **是什么：** 任务失败时的单一主因标签，协议字段名 `attribution`。六选一：`PROTOCOL` / `CONTEXT` / `MODEL_SCHEMA` / `MODEL_TASK` / `TOOL` / `HARNESS`。禁止无归因红灯。`HARNESS` 是失败分类名，不是产品名。
- **不是什么：** 不是试题字段；题目上的 `attribution_focus` 不得把额度 / CONTEXT 改写成 `MODEL_TASK`。
- **哪儿用过：** [需求 01](01-prd.md) · [设计 07](../v1-design/07-hosted-attribution-tree.md)

## 5. 协议词（原 PRD 附录 E）

下列词只在本篇定义。需求 01 正文仍使用这些词，但附录不再另列表。

### axis

- **是什么：** 评测轴 A/B/C 或显式交集（AB/AC/BC）。
- **哪儿用过：** [需求 01](01-prd.md) · [测试 02](../test/02-engine-regression.md)

### layer

- **是什么：** A 轴内层级 L1 / L2 / L3。
- **哪儿用过：** [需求 01](01-prd.md) · [设计 03](../v1-design/03-fold-entry-contract.md)

### case_rev

- **是什么：** 试题修订号，与结果绑定。协议字段现为 `item_rev`（[ADR-0006](../architecture/adr/0006-final-review-decisions.md)）；含义不变。
- **哪儿用过：** [需求 01](01-prd.md) · [需求 03](03-bank-editor-prd.md)（界面称「版本」）

### freeze

- **是什么：** 一次跑次钉死的因子快照。
- **哪儿用过：** [需求 01](01-prd.md) · [测试 01](../test/01-wanxiangshu-ops.md)

### oracle

- **是什么：** 机器判定器（`expect.oracles`）。人话见「怎样算对」。
- **哪儿用过：** [需求 01](01-prd.md) · [测试 01](../test/01-wanxiangshu-ops.md)

### suite

- **是什么：** 原 PRD 用语：用例集合 + profile 绑定。对人即「测试集」加运行环境；磁盘仍是 `paperset` + 房间文件，定义见上文，不在此另写一套。
- **哪儿用过：** [需求 01](01-prd.md) · [ADR-0006](../architecture/adr/0006-final-review-decisions.md)

### baseline

- **是什么：** 命名的历史跑次，用于 compare。
- **哪儿用过：** [需求 01](01-prd.md) · [设计 08](../v1-design/08-console-outline.md)

### scripted model

- **是什么：** 预置回复 / 工具调用的剧本模型驱动。
- **哪儿用过：** [需求 01](01-prd.md) · [设计 05](../v1-design/05-scripted-model.md)

### contract verify

- **是什么：** 对真宿主运行契约验证 suite（v2）。
- **哪儿用过：** [需求 01](01-prd.md) · [测试 02](../test/02-engine-regression.md)

### stimulus

- **是什么：** 试题刺激（题干引用、暗号等）。界面用「题干 / 怎样算对」，不直接抛这个英文。
- **哪儿用过：** [需求 03](03-bank-editor-prd.md) · [ADR-0006](../architecture/adr/0006-final-review-decisions.md)
