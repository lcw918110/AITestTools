## 1. 背景与问题

引擎 `agent-proctor` 已能跑同题对照。日常要在本机完成：**建一条测试任务 → 选题并开跑 → 看这次的明细与分析 → 维护题库**，不必记命令。

---

## 2. 用户与场景

| 角色       | 场景                                               | 状态                                          |
| :--------- | :------------------------------------------------- | :-------------------------------------------- |
| 评测人员   | 保存多条测试任务 → 运行测试 → 在测试结果看明细与 Δ | 测试任务可保存；结果分明细/分析，默认最近一次 |
| 题库维护者 | 录 / 改 / 删 / 检查                                | 已验收（需求 03）                             |
| 开发者     | CLI；控制台调同一引擎                              | 现行                                          |

---

## 3. 信息架构（三页）

词义见 [00-glossary.md](00-glossary.md)。顶栏 **测试 | 题库 | 运行环境**（hash：`#test` / `#bank` / `#env`）。测试页 = 测试任务 + 测试结果。一次开跑 = 测试集 × 运行环境。零新路由框架。

| 块             | 现行                                                                                                                                  |
| :------------- | :------------------------------------------------------------------------------------------------------------------------------------ |
| **测试任务**   | 可保存多条；类型新建时三选一、之后只读；选测试集；本题要跑的题目（勾选不写回测试集）；测万象术才有无插件；模型/Agent 只从已验证项下拉 |
| **测试结果**   | 挂在当前任务下：逐条明细 + 本次分析；默认最近一次跑次；可点开更早跑次                                                                 |
| **题库**       | 独立页；按测试集筛；录题必选或新建测试集                                                                                              |
| **运行环境页** | 增改模型 / Agent，Hello World 验证后才进任务下拉；写入 `rooms/` 下的配置清单（含点文件，引擎不读）                                    |

经济图有跑次后再画；「看板」留给以后观察多次测试，本刀不用这个名字。

### 3.1 测试任务

词义见术语篇「测试任务」「测试集」「本题要跑的题目」「运行环境」。

1. **可保存多条。** 每条绑定：实验类型、测试集、本题要跑的题目、运行环境快照、历次跑次。JSON 落在 `examples/product-eval/eval-tasks/`，不写 `localStorage`。勾选不写回测试集文件。
2. **三种实验互斥：** 测模型 / 测万象术 / 测 Agent **只在新建对话框三选一**。打开已有任务只显示只读标签。换类型 = 新建另一条。
3. **有无插件**（无插件 / 有插件 / 同时跑）**只出现在测万象术**，属于运行环境，不是两套测试集。测万象术默认同时跑。测模型、测 Agent 界面不出现这三项。同时跑 = 同一套模型、同一套 Agent，先无插件再有插件。
4. **测试集：** 下拉只按「考哪些题」列一份（效果小样本 / 校准 / 全量 / 冒烟 / 自建）。不出现 `paired-off`、`paired-on`、`eval-model`、`eval-agent`。列表标题为「本题要跑的题目」；每行须有题号、任务类型、简介、题干。不做完整测试集编辑器。
5. **运行环境快照：** 模型、Agent 从已验证下拉必选（真跑）；选一次记在这条任务上，不覆盖配置清单、不随配置页改动自动变。测万象术另填万象术仓库路径。「只检查题库，不真跑」放在「高级」。默认倾向真跑。离线只检查可不选模型/Agent。
6. 开跑时测试集 × 运行环境。测万象术同时跑则同号 OFF+ON；缺一侧标不完整，有的一侧照跑。
7. 没改过测试集、有无插件、勾选时，测万象术真跑仍走现在的默认绑卷（不改 `eval:paired` 绑 156）。

明确不做：用途字段；改 npm 脚本默认绑卷；难度录入（T5 后半）；完整测试集编辑器；在任务页新建模型/Agent。

### 3.2 测试结果

打开当前测试任务后，默认展示**最近一次**跑次。内容分两块：

1. **明细：** 逐题绿红、工作区 / 暗号 / 超时等逐条信号。
2. **分析：** 针对这次明细的 Δ（剔除 CONTEXT 后）、配置回放、归因、对照摘要。剔除规则见术语篇「CONTEXT」「Δ」。

任务下挂全部跑次历史，需要时再打开更早一次。不把全库 `runs/` 当成与任务无关的总看板。

### 3.3 题库

录入/编辑规则以 [03-bank-editor-prd.md](03-bank-editor-prd.md) 为准。词义见术语篇「人题」「测试集」「任务类型」。列表按测试集筛（可看全部）。录题必选或新建测试集，新题写入该集正式名单（不自动进 156 全量，除非选的就是全量）。改完题后切到测试页开跑。向导可选任务类型；难度本刀不录入。

### 3.4 运行环境页

在顶栏「运行环境」增改模型与 Agent。新项写入 `rooms/` 配置清单（点文件 `rooms/.console-catalog.json`，引擎跳过点文件；Agent 还写入各 hosted 房间的 `managed_agents`）。验证 = 用该模型 + 该 Agent 发一次 Hello World 级操作且成功。未通过的不进测试任务下拉。本刀不单独验插件是否加载。

## 4. 非目标

- 不替代引擎协议与 CLI；控制台只编排与读写约定字段
- 不做云端多租户；仅 `127.0.0.1`
- 不改 papers-v1 schema 的成对落盘方式（UI 仍只暴露一道题）
- 不做通用多模型 BI；效果对照只用固定小矩阵（已在测试结果）
- 不把 156 全量自动当成效果结论
- 不改万象术业务逻辑
- 不做「测试看板」多任务总览（留给以后）
- 不做完整测试集编辑器；改题页不把一题再挂进另一套测试集
- 不扩 papers-v1 / `room.schema.json`

## 5. 数据与约束

| 项             | 约束                                                                                  |
| :------------- | :------------------------------------------------------------------------------------ |
| 项目根         | 固定 `examples/product-eval`（本阶段不切换考卷库）                                    |
| 题号           | `^[A-Z][A-Z0-9-]*$`，建议 `PAIRED-TASK-NN`                                            |
| 测试任务 id    | `et-` 加字母数字；文件在 `eval-tasks/`                                                |
| 读写边界       | `bank/`、相关 `papersets/*.json`、`rooms/`（配置页）、`eval-tasks/`、`runs/` 只读展示 |
| 本题要跑的题目 | 见 [术语篇](00-glossary.md#本题要跑的题目)；不写回测试集文件                          |
| 安全           | 禁止路径穿越；拒绝仓库外路径                                                          |

题库可编辑字段仍以需求 03 为准（题干、终态词、notes + 强制升版本）。

## 6. 成功标准

| 块         | 标准                                                                                                                   |
| :--------- | :--------------------------------------------------------------------------------------------------------------------- |
| 测试结果   | 不读 JSON 能说出这道题谁过谁挂、Δ 能不能用；默认最近一次                                                               |
| 测试任务   | 能保存多条；类型创建后只读；测万象术才见插件选项；测试集下拉无人话文件名；本题要跑的题目见简介和题干；勾选不写回测试集 |
| 题库 B     | 独立页；按测试集筛；录题必选测试集；改题升版本；向导可选任务类型                                                       |
| 运行环境页 | 能增改模型/Agent；未验证不进任务下拉；验证为 Hello World 操作成功                                                      |

可测门禁：`GET /api/runs/view` 含 `dashboard`；`GET/POST /api/eval-tasks`；`npm run console:smoke`；题库 C-B-* 见测试 03。
