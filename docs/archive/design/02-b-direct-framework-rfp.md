## 1. 适配面（先于选型）

`drivers/model-adapter` 只依赖：

| 面                        | 内容                                                                                           |
| ------------------------- | ---------------------------------------------------------------------------------------------- |
| 输入 `EvalJob`            | 试题列表、假工具 fixture、断言（schema_obedience / tool_trace）、`repeats`（默认 3）、模型列表 |
| 输出 `FrameworkRawResult` | 可解析 JSON → 收编为 `results.ndjson` + harness 指标                                           |

换框架 = 换 adapter 实现；门禁只看收编后指标（PRD §9）。

## 2. 候选对比（公开信息摘要，实现前需再跑 spike）

| 维度               | promptfoo                                               | Inspect-AI                     |
| ------------------ | ------------------------------------------------------- | ------------------------------ |
| 主语言 / 安装      | Node / npm                                              | Python / pip                   |
| 与本引擎（TS）亲和 | **高**（同进程或子进程都顺）                            | 中（必须子进程 + JSON 桥）     |
| 本地可跑           | 是（CLI `promptfoo eval`）                              | 是（`inspect eval`）           |
| JSON 导出          | 支持（如 `--output` JSON/JSONL）                        | 支持结果导出；需 spike 钉字段  |
| 工具调用断言       | 有，且持续向 agent 场景扩展                             | 强于多步 agent / solver 编排   |
| 许可证             | MIT（OSS）                                              | MIT（UK AISI）                 |
| 组织风险           | 2026 起并入 OpenAI 生态；OSS 宣称保留，中立性需持续观察 | 独立安全评测生态，学习曲线更高 |
| 矩阵 / CI          | 强（YAML 矩阵、exit code）                              | 强（任务组合、可复现实验）     |

**评分建议（权重）**：TS 亲和 25 · 工具断言 25 · JSON 导出稳定 20 · 本地/CI 15 · 许可证与中立 15。

## 3. 推荐结论（供终审，非正式锁定）

| 建议                                | 说明                                                                                      |
| ----------------------------------- | ----------------------------------------------------------------------------------------- |
| **Phase 1 默认 spike：`promptfoo`** | 与 `agent-proctor` 同属 Node 生态，集成成本最低；满足 PRD「本地 / JSON / 工具断言 / MIT」 |
| **保留 Inspect adapter 接口**       | 若工具多步编排或安全评测题库变主场景，再加第二个 adapter                                  |
| **不锁死进 ADR**                    | 完成 2 模型 × ≥5 case × repeats=3 的 spike 后，另立 ADR-0006 锁定默认                     |

门禁与 LLM-judge：PRD 写明 LLM-judge **不进门禁**；若框架默认带 model-graded，adapter 必须可关闭且 gate 只用确定性断言。
