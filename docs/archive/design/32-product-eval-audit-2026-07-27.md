# 产品原则审核：模型 · Agent · 万象术类插件

| 字段     | 值                                                                           |
| :------- | :--------------------------------------------------------------------------- |
| 状态     | **审核结论（2026-07-27）** · **建议 1–4 已最小面落地**（见文末「落地状态」） |
| 原则来源 | 用户拍板：三测试对象 + 题库/效果/打分优先                                    |
| 范围     | 本仓实现、题库资产、默认脚本、文档叙事                                       |

---

## 1. 原则（审核尺子）

| 优先级              | 内容                                                                                                             |
| :------------------ | :--------------------------------------------------------------------------------------------------------------- |
| **P0 测试对象**     | ① **模型** ② **Agent**（宿主，如 OpenCode）③ **万象术类插件**                                                    |
| **P1 也要有**       | **工具**（CLI/壳）契约与边界——支撑解释「坏在工具还是没用上」                                                     |
| **P2 跑起来更重要** | **题库**（真实任务资产）→ 对三对象的 **效果结果** → 可汇报的 **测试打分/分差**（可参考栏；硬门禁仍宜确定性断言） |

实验原形（测插件效果时）：

```text
固定：同一 Agent + 同一模型 + 同一任务输入
自变量：有无万象术类插件（或换模型 / 换 Agent，一次只变一个）
输出：效果结果 +（可选）质量分
```

引擎 A/B/C（Fold / direct·hosted / shell）是**实现分层**，不是产品测试对象。

---

## 2. 总评

| 维度           | 判定               | 一句话                                                                         |
| :------------- | :----------------- | :----------------------------------------------------------------------------- |
| 测模型         | **半成品**         | demo `model-core` 能跑 schema 服从；缺真实任务效果题库与跨模型效果表           |
| 测 Agent       | **半成品**         | 假宿主 + 真 hosted + contract 有；缺「换宿主/换版本」效果对比题库              |
| 测万象术类插件 | **偏工程、弱效果** | Fold/ST 与 hosted 挂插件 smoke 强；**同任务有无插件配对题库与效果报表缺失**    |
| 测工具         | **可用**           | C 轴 echo/write + `st-real-git` 已绿；属支撑面，不宜当产品主叙事               |
| 题库           | **错位**           | 厚度在回归（L1 ST、schema fixture），不在「真实任务效果」                      |
| 效果 / 打分    | **缺口大**         | 产物以 pass/fail + 归因为主；无质量分、无配对增益报表；PRD 禁 LLM-judge 进门禁 |

**一句话**：当「监考引擎」能跑；当「评模型 / Agent / 插件效果并打分的产品」——题库与结果层尚未对齐原则。

---

## 3. 对照表（原则 → 现状 → 缺口）

### 3.1 ① 模型

| 项       | 现状                                             | 缺口                                        |
| :------- | :----------------------------------------------- | :------------------------------------------ |
| 能力     | B-direct（promptfoo）；`--models`；fixture/live  | 真实多步任务效果集薄                        |
| 题库     | `demo-project` / `model-core`（schema 服从为主） | 缺「同 Agent、同任务、换模型」效果 paperset |
| 结果     | `b_schema_*`、`b_required_tool_call_*` 等        | 缺任务成功质量分、跨模型对照表              |
| 默认路径 | `smoke:offline` 含 model-core fixture            | 不体现「选型效果」叙事                      |

### 3.2 ② Agent

| 项   | 现状                                                            | 缺口                                    |
| :--- | :-------------------------------------------------------------- | :-------------------------------------- |
| 能力 | L2 假宿主、B-hosted 真 OpenCode、`contract verify`、L3 cassette | 换 Agent 产品几乎未建模                 |
| 题库 | demo `smoke-A` / `hosted-smoke`（常无插件）                     | 缺「同模型、同任务、换 Agent/版本」配对 |
| 结果 | 契约 probe、hosted 退出与日志                                   | 缺 Agent 维度效果分与回归基线产品化     |
| 风险 | 宿主钉死 OpenCode 1.18.5                                        | 原则要求「测 Agent」，实现却几乎单宿主  |

### 3.3 ③ 万象术类插件

| 项       | 现状                                                       | 缺口                                         |
| :------- | :--------------------------------------------------------- | :------------------------------------------- |
| 能力     | L1 Fold 直测、hosted 挂 `plugin`、NDJSON 归因              | **效果评测**未一等公民化                     |
| 题库     | `st-import-L1`（13）强；`hosted-smoke` 仅 **有插件** smoke | **无** `paired-off`/`paired-on` 同任务对照集 |
| 结果     | Fold pass、NDJSON 有无、归因标签                           | 无「有插件增益」；无质量分差                 |
| 默认路径 | `smoke:wanxiangshu` = Fold + C git                         | **不含**有无插件效果对比                     |

### 3.4 工具（P1）

| 项   | 现状                   | 缺口                              |
| :--- | :--------------------- | :-------------------------------- |
| 能力 | C 壳、`st-real-git`    | 与「经 Agent 调工具」效果题未打通 |
| 定位 | 解释 TOOL 归因的支撑面 | 勿挤占题库主精力                  |

### 3.5 题库 · 效果 · 打分（P2）

| 项       | 现状                              | 缺口                                                                                           |
| :------- | :-------------------------------- | :--------------------------------------------------------------------------------------------- |
| 题库     | 回归题多、任务题少                | 需按三对象建**效果题库**（真实 prompt + 可判定成功标准）                                       |
| 效果结果 | `results.ndjson` pass + artifacts | 需配对对照表（off/on 或 model A/B）                                                            |
| 打分     | 无；PRD：LLM-judge **不进门禁**   | 可做：**参考分**（人工量表 / 可选 judge 栏）+ 确定性门禁并行；`compare` 需能比分差而不只比布尔 |
