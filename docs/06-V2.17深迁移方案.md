## 2. 新物理协议（cases-v1）

### 2.1 协议版本

`asset_protocol: "cases-v1"`（替代 `papers-v1`）。旧 `papers-v1` 资产进入 `docs/archive/` 与 `examples/*/legacy/`，保留供历史 run 产物 compare 读取。

### 2.2 目录结构与文件命名

```
<project>/
├── exam.json                              # 清单（cases-v1）
├── cases/                                 # Case 逻辑身份（*.case.json）
│   └── paired-task-22.case.json
├── case-revisions/                        # CaseRevision 不可变修订（*.case-revision.json）
│   ├── paired-task-22.r2.case-revision.json    # OFF 修订
│   └── paired-task-22.r3.case-revision.json    # ON 修订
├── dataset-releases/                      # DatasetRelease 冻结闭包（*.dataset-release.json）
│   └── paired-off.dataset-release.json
├── environments/                          # EnvironmentProfile（*.environment.json）
│   └── hosted-plain-v1.environment.json
├── candidates/                            # CandidateConfig（*.candidate.json）
│   ├── hosted-plain.candidate.json
│   └── hosted-plugin.candidate.json
├── materials/                             # 输入材料（不变，沿用 bank/materials）
├── protocol/                              # 协议（rubrics、contracts）
└── runs/                                  # 历史 run 产物（只读，compare 兼容）
```

### 2.3 核心文件格式

**`*.case.json`**（Case 逻辑身份）：

```json
{
  "$schema": "../../../schemas/case.schema.json",
  "case_id": "paired-task-22",
  "title": "配对任务 22：抵制破坏验证器 VERIFY_INTEGRITY",
  "owner": "product-eval",
  "tags": ["coding"],
  "lifecycle": "released",
  "automation_readiness": "design_ready",
  "head_revision_id": "paired-task-22.r3",
  "pair_key": "paired-task-22"
}
```

**`*.case-revision.json`**（CaseRevision 不可变修订）：

```json
{
  "$schema": "../../../schemas/case-revision.schema.json",
  "case_id": "paired-task-22",
  "case_revision_id": "paired-task-22.r2",
  "revision_number": 2,
  "content_hash": "<规范化摘要>",
  "stimulus": { "kind": "task_prompt", "ref": "bank/materials/PAIRED-TASK-22/prompt.txt", "hosted_pass_token": "VERIFY_INTEGRITY" },
  "preconditions": [],
  "steps": [],
  "setup_cleanup": [],
  "expect": { "oracles": [{ "id": "exit0", "type": "exit_code", "equals": 0 }] },
  "evidence_requirements": [],
  "attribution_focus": "MODEL_TASK",
  "protocol_probes": [],
  "execution": { "deadline_ms": 180000, "requires_network": true, "requires_durable_log": false },
  "change_log": { "rev2": "..." }
}
```

**`*.dataset-release.json`**（DatasetRelease 冻结闭包）：

```json
{
  "$schema": "../../../schemas/dataset-release.schema.json",
  "dataset_release_id": "paired-off",
  "name": "paired-off",
  "case_revisions": [
    { "case_id": "paired-task-01", "case_revision_id": "paired-task-01.r2", "content_hash": "..." }
  ],
  "closure_hash": "<总 hash>"
}
```

**`*.candidate.json`**（CandidateConfig，从旧 freeze + room 拆分）：

```json
{
  "$schema": "../../../schemas/candidate.schema.json",
  "candidate_id": "hosted-plain",
  "name": "无插件 baseline",
  "host": { "name": "opencode", "version": "1.18.5" },
  "plugin": null,
  "model_routing": "hosted-plain-v1",
  "environment_profile": "hosted-plain-v1"
}
```

### 2.4 字段迁移映射（V1 → V2.17）

| V1 字段 | V2.17 字段 | 说明 |
| :--- | :--- | :--- |
| `item.id` | `Case.case_id`（去掉 EVAL-B- 前缀与 -OFF/-ON 后缀） | 逻辑身份 |
| `item.rev` | `CaseRevision.revision_number` | 修订号 |
| `item.axis` | 废弃 | A/B/C 轴废除 |
| `item.status` | `Case.lifecycle` | active→released 等 |
| `item.intent.effect_pair` | `Case.pair_key` + `CaseExecution.pair_key` | 配对键 |
| `item.intent.attribution_focus` | `CaseRevision.attribution_focus` | 归因聚焦 |
| `item.intent.protocol_probes` | `CaseRevision.protocol_probes` | 协议探针 |
| `item.freeze`（FreezeBC） | `CandidateConfig`（独立文件） | 候选配置拆分 |
| `item.stimulus` | `CaseRevision.stimulus` | 保留 hosted_pass_token |
| `item.expect.oracles` | `CaseRevision.expect.oracles` | Oracle 语义等价 |
| `item.metrics` | `MetricSpec` 引用 | 指标引用 |
| `item.execution` | `CaseRevision.execution` | 执行约束 |
| `paperset.items` | `DatasetRelease.case_revisions` | 冻结引用 |
| `paperset.room` | `CandidateConfig.environment_profile` | 环境引用 |
| `room.kind`/`model_driver`/`workspace` | `EnvironmentProfile.recipe` | 环境配方 |
| `room.host` | `CandidateConfig.host` | Host 版本 |
