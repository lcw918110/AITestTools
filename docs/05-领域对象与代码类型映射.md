# 05 · 领域对象与代码类型映射

| 字段   | 值                                                         |
| :----- | :--------------------------------------------------------- |
| 状态   | **现行**                                                   |

本文是 **V2.17 领域对象 ↔ 代码类型** 的权威映射表，作为文档与代码之间的契约锚点。领域对象的语义权威在 [02-总体架构与领域设计.md](02-总体架构与领域设计.md) §3；代码类型的唯一来源是 [`src/domain/types.ts`](../src/domain/types.ts)。

> 约定：**文档对象名 = 代码类型名**，一一对应，不允许两套命名。旧 V1 类型（`ItemDoc`/`PapersetDoc`/`RoomDoc` 等）在 [`src/exam-engine/types.ts`](../src/exam-engine/types.ts) 中保留为 `@deprecated` 兼容接口，仅用于迁移期，不作为权威模型。

## 11. V1 → V2.17 迁移映射（§3.2）

| V1 旧类型（@deprecated） | V2.17 权威类型 | 迁移规则 |
| :--- | :--- | :--- |
| `ItemDoc` | `Case` + `CaseRevision` | `id` → `case_id`；`rev` → `revision_number`；`intent.effect_pair` → `PairKey`；`freeze` → `CandidateConfig` |
| `PapersetDoc` | `DatasetRelease` | `items` → `case_revisions`；`axis`/`room`/`matrix_env`/`gates` 废弃 |
| `RoomDoc` | `EnvironmentProfile` | `kind`/`model_driver`/`workspace` 等废弃，迁移为 `recipe` |
| `ExamManifest` | `RunPlanSnapshot` | `asset_protocol` 废弃 |
| `FreezeA` / `FreezeBC` | `CandidateConfig` | `layer`/`model_driver`/`fold_entry`/`session_id` 等废弃 |
| `AXES` / `Axis` / `ALayer` | — | A/B/C 轴、L1/L2/L3 轴已废除 |
