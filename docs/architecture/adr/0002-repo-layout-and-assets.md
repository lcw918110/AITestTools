# ADR-0002：仓库形态与用例资产归属

| 字段   | 值                       |
| :----- | :----------------------- |
| 状态   | **已采纳**               |
| 日期   | 2026-07-25               |
| 决策人 | 项目初始化（按推荐默认） |

## 背景

PRD 要求「Runner 独立仓库；用例/夹具资产留在被测仓库」。引擎需要自测样例，又不能把正式题库绑死在引擎仓库。

## 决策

1. **仓库形态：单包**（非 monorepo）。模块用目录分隔：`case-engine` / `drivers` / `oracles` / `attribution` / `metrics` / `report` / `contract` / `cli`。
2. **正式资产 = 题库/考卷**：由被测项目持有；目录隐喻见 **ADR-0005**。引擎通过 `--project <path>` 指向资产根。
3. **本仓库样例与副本**：
   - `examples/demo-project`：引擎自测样板
   - `examples/<sut>-papers/`：**外部题库本地副本**（运行默认路径；同步策略见 **ADR-0008**）
4. **`40-评测工具/`**：需求与 Phase 0 历史；不作为运行时默认资产根。
5. **多被测**：`wanxiangshu` 为首个适配样例；Fold/宿主由 room 配置。

## 后果

- 正面：符合 PRD；引擎可独立版本演进；被测侧资产与产品同仓；目录对业务方可读。
- 负面：跨仓库路径与 CI 编排需约定；本仓库不能单独声称「正式题库完备」；与 Phase 0 `cases/` 命名需迁移映射。
