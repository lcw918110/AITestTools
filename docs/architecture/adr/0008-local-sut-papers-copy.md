# ADR-0008：外部题库本地副本

| 字段 | 值                                               |
| :--- | :----------------------------------------------- |
| 状态 | **已采纳**                                       |
| 日期 | 2026-07-27                                       |
| 依据 | 用户：外部题库在引擎仓留副本，运行时调用本地题库 |

## 背景

PRD / ADR-0002：正式题库归属被测仓库。引擎开源后，若每次运行都依赖邻仓路径，则 CI/克隆本仓无法自洽复现。

## 决策

1. **权威源**：被测仓题库（如 `wanxiangshu/papers`）仍为产品侧权威。
2. **引擎仓副本**：`examples/<sut>-papers/` 保留同步副本；**运行默认 `--project` 指向该副本**。
3. **同步**：`npm run sync:papers -- wanxiangshu`（排除 `runs/`）；同步后应跑离线冒烟。
4. **SUT 构建产物**：Fold/Plugin 仍通过 `SUT_ROOT` 指向被测仓根（读 `build/`）；题库 JSON/材料走本地副本。
5. **禁止**：把副本 `runs/` 与 `.env` 提交进引擎仓。

## 后果

- 正面：开源仓可独立演示；与被测仓解耦日常路径。
- 负面：需定期 sync，存在短暂漂移窗口。
